# Asset Attribution

This package includes SVG anatomy assets under `anatomy_graphdb/assets/anatomy/`.

## Distribution Requirement

Before each public release, confirm:

1. The project has rights to redistribute every bundled SVG.
2. Required attribution text (if any) is included in repository docs.
3. License terms are compatible with PyPI distribution and MIT-licensed code packaging.

## Current Policy

- Code is licensed under MIT (`LICENSE`).
- Asset licensing must be verified separately from code licensing.
- If an asset cannot be redistributed, remove it from the packaged manifest before release.
